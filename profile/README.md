# Research-Ready

Digitaal soevereine AI-pipelines voor onderzoek, overheid en bedrijfsleven: acht zelfsturende
productiepipelines op een zelf-gehoste AI-stack.

## Pipelines

1. [uc1-research](https://github.com/Research-Ready/uc1-research) — citable reproducible research
2. [uc2-app-builder](https://github.com/Research-Ready/uc2-app-builder) — app + serious games builder
3. [uc3-chatbot-voice](https://github.com/Research-Ready/uc3-chatbot-voice) — chatbot with voice
4. [uc4-supply-chain](https://github.com/Research-Ready/uc4-supply-chain) — supply chain visualization
5. [uc5-business-creation](https://github.com/Research-Ready/uc5-business-creation) — business creation pipeline
6. [uc6-model-creation](https://github.com/Research-Ready/uc6-model-creation) — specialized model creation
7. [uc7-careermaker](https://github.com/Research-Ready/uc7-careermaker) — careermaker
8. uc8-survey-report — survey report (client: Dundir)
